
# NIGHTWATCH EVP
### Paranormal Investigation System

A military-style night investigation app for Android.

## Planned Features

- EVP audio recording and playback
- Video evidence recording
- Investigation session logs
- Audio waveform and noise analysis
- Evidence archive and timestamps
- Supported phone sensor readings
- Night-vision-inspired interface

## Development

Built with Flutter and Dart.

## Evidence Integrity

Original recordings should be preserved separately from enhanced copies. Audio analysis can help investigate unexplained sounds but cannot independently establish paranormal activity.
